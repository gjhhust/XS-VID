XS-VID v2 Download and Reproduce

Download the dataset

Use Python and Git. The YOLOFT downloader uses the Python standard library: no hub SDK installation is needed. It downloads the release, verifies media-archive SHA-256 checksums, extracts images and generates portable labels, split lists and the Detection YAML bridge.

Allow about 34 GB for downloads, plus additional space for extracted images and labels. Replace ./downloads with your destination directory.

git clone https://github.com/gjhhust/YOLOFT.git
cd YOLOFT
python tools/xsvid/download_release.py --hub ms --destination ./downloads

ModelScope is the domestic dataset mirror. Alternatively, use Hugging Face:

python tools/xsvid/download_release.py --hub hf --destination ./downloads

Dataset mirrors: ModelScope / Hugging Face.

Both dataset mirrors and the HF YOLOFT-L model package are public. Repository visibility and anonymous metadata/document access are verified; the full anonymous dataset CLI run is a separate check.

Download the models

Reproduction evidence index / Evidence ZIP: actual inference metrics, startup/save/reload receipts, source and checkpoint hashes, and bounded job logs. Anonymous VID/MOT/SOT checkpoint strict loading passed with zero missing or unexpected keys. Full anonymous dataset extraction is still being checked.

The HF model package supplies task-specific YOLOFT-L Detection, MOT and SOT checkpoints, portable TransT initialization and OSNet weights. Model download verifies their pinned hashes; it does not verify every paper benchmark row.

python tools/xsvid/download_release.py --hub hf --component model --destination ./downloads

To fetch both the dataset and models from HF in one command, use --hub hf --component all with the same destination. Model package.

Run and evaluate

Follow the YOLOFT README for runtime dependencies, full VID/MOT/SOT inference commands and the bounded training-startup command. Download preparation does not install CUDA operators or run GPU inference.

  • Paper reproduction: the downloader defaults to --detection-protocol paper, using annotations/protocols/paper_detection_test.json.
  • New Detection results: add --detection-protocol canonical to use corrected annotations/test.json.
  • New MOT results use canonical track_id; paper reproduction uses paper_track_id with fallback to track_id.
  • SOT uses the 272 sequences in sot/test.txt and their official target trajectories.

Download revisions and existing files

Record the code commit and mirror revision for repeatable experiments. HF defaults to main and ModelScope to master; pass --revision YOUR_RECORDED_REVISION to pin a revision. Dataset and model repositories have independent revisions.

Rerunning the command verifies and reuses files with known hashes, then repeats preparation. Failed individual transfers are retried, not byte-range resumed. Use --offline to verify and prepare an already complete download. The success marker RELEASE_PREPARED means integrity/preparation only, not GPU reproduction.

SDK download alternatives and manual validation

These optional SDK commands download repository files only. Unlike the main CLI workflow, extraction and label preparation must be run separately.

python -m pip install -U huggingface_hub
python -c 'from huggingface_hub import snapshot_download; snapshot_download(repo_id="lanlanlan23/XS-VID-v2", repo_type="dataset", local_dir="./downloads/XS-VID-v2")'
python -m pip install -U modelscope
python -c 'from modelscope.hub.snapshot_download import dataset_snapshot_download; dataset_snapshot_download(dataset_id="lanlanlanrr/XS-VID-v2", local_dir="./downloads/XS-VID-v2")'

For SDK downloads, verify archives/manifest.json and its archive hashes before extraction, then prepare the portable layout from the YOLOFT code root:

for archive in ./downloads/XS-VID-v2/archives/XSVID_v2_images_*_of_16.tar; do
  tar -xf "$archive" -C ./downloads/XS-VID-v2 || exit 1
done
python tools/xsvid/prepare_legacy_layout.py --data-root ./downloads/XS-VID-v2 --detection-protocol paper --regenerate-labels

Optional annotation and referenced-media checks run from the downloaded dataset root. Keep the complete tools/ directory, including the validators' build_unified_annotations.py dependency:

cd ./downloads/XS-VID-v2
python tools/validate_release_annotations.py annotations/train.json --output xsvid_train_validation.json
python tools/validate_release_annotations.py annotations/test.json --output xsvid_test_validation.json
python tools/validate_release_media.py --root . --output xsvid_media_validation.json

These validators check annotations and referenced file presence; the media validator does not hash image pixels. SDK references: Hugging Face and ModelScope.
